# Trump Tweets and Stock Market Impact

## Objective
To analyze whether Trump's tweets have statistically significant impact on sector-level stock returns.

## Data
- Trump tweet dataset (2016–2020)
- S&P500 sector ETF daily prices
- Market benchmark (SPY)

## Methodology
- Event study framework
- Market model for abnormal return, volatility
- 1-hour(short term,(-1h, +h)) and 5-day(long term,(-5d,+5d)) event window
- t-test for significance

## Tools
Python (Pandas, NumPy, Matplotlib, Statsmodels)

## Key Findings
- Short-term spikes in High-Tech and information-sensitive sector.Effects concentrated rather than market-wide
- No systematic long-term persistence
